# Description

Adds ratio group and priority options to the rTorrent action.

* Priority: Default / Low / Normal / High, sent as `d.priority.set` on add. Stored in the existing `priority` column as new `LOW`/`NORMAL`/`HIGH` values
* Ratio group: free-text ruTorrent ratio group (`rat_0`..`rat_7`), assigned with a `view.set_visible` load command. New `ratio_group` column on `action`
* The action checks `view.list` before adding and fails if the group does not exist, since rTorrent would otherwise add the torrent stopped and hash-failed while reporting success
* Bumps `go-rtorrent` to a pseudo-version for `Command`, `DPriority` and `Views()` - swap for the tag once released
